# EventHub Admin Portal

| Page Name | Purpose | UI Components | Functionality |
| :--- | :--- | :--- | :--- |
| **Admin Dashboard** (`dashboard.html`) | Master platform control. | Global stats, revenue aggregates, system health alerts. | High-level monitoring of platform-wide activity. |
| **Approvals** (`approvals.html`) | Quality control. | New event queue, organizer application list, preview button. | Reviewing and approving/rejecting submitted content. |
| **Manage Users** (`users.html`) | User governance. | Master user list, account status toggles (active/banned). | Managing attendee access and resolving user issues. |
| **Organizers** (`organizers.html`) | Partner governance. | Partner directory, revenue ranking, compliance status. | Overseeing organizer performance and verification. |
| **Coupons Admin** (`coupons.html`) | Marketing control. | Code creator, usage charts, expiration management. | Launching platform-wide marketing campaigns. |
| **Global Refunds** (`refunds.html`) | Final financial oversight. | Escrow management, bank transfer logs, bulk actions. | Overseeing refund flows between organizers and users. |
| **Master Reports** (`reports.html`) | Strategic insights. | Advanced BI charts, demographic breakdowns, trend predictions. | Generating deep-dive data for business growth. |
| **System Logs** (`logs.html`) | Technical health. | Real-time event log, error tracking, login activity. | Monitoring security and platform stability. |
| **Settings** (`settings.html`) | Platform configuration. | Fee management, API keys, maintenance mode toggle. | Controlling the technical levers of the entire site. |
| **Admin Profile** (`profile.html`) | Personal data. | Avatar, email, platform role. | Managing administrator account details. |
