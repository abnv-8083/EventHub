# EventHub User Portal

| Page Name | Purpose | UI Components | Functionality |
| :--- | :--- | :--- | :--- |
| **Dashboard** (`dashboard.html`) | Personal hub for attendees. | Stat cards (tickets, upcoming), recent activity, quick navigation. | Overview of personal bookings and recent interactions. |
| **My Calendar** (`mycalendar.html`) | Visual booking management. | Interactive monthly grid, event highlight markers, side-info panel. | Viewing events in a calendar view, quick-checking event days. |
| **My Tickets** (`tickets.html`) | Pass & Attendee management. | Pass list, individual cancellation buttons, active/past filters. | Managing entry passes, cancelling individual attendees, viewing QR codes. |
| **Ticket Details** (`ticket-details.html`) | Entry pass for one attendee. | Attendee name/phone, QR code, Print/Share options. | Displaying proof of purchase and attendee info for scanning. |
| **Wishlist** (`wishlist.html`) | Saved events for future purchase. | Bookable event cards, "Remove" triggers. | Keeping track of interesting events before booking. |
| **My Coupons** (`coupons.html`) | Offer discovery and tracking. | Dashed-border coupon cards, copy-to-clipboard codes. | Viewing active and upcoming platform discounts. |
| **Refund Center** (`cancel.html`) | Primary listing of refundable bookings. | Event status cards, eligibility badges, "Manage" triggers. | Viewing upcoming events eligible for cancellation/refund. |
| **Cancel Detail** (`cancel-detail.html`) | Individual attendee/ticket selector. | Custom checkboxes, live refund breakdown, attendee cards. | Picking specific people within a booking to cancel. |
| **Cancel Confirm** (`cancel-confirm.html`) | Final review of refund numbers. | Reason dropdown, platform fee display, policy confirmation. | Submitting final reasons and agreeing to platform rules. |
| **Cancel Success** (`cancel-success.html`) | Confirmation of submitted request. | Success icon, estimated bank credit summary, direct tracking link. | Acknowledging that the refund request is in progress. |
| **Refund Status** (`refund-status.html`) | Financial tracking. | Status tracker (stepper), bank processing info. | Monitoring the progress of submitted refund requests. |
| **Manage Profile** (`profile.html`) | Personal data management. | Avatar upload, bio editor, social link inputs. | Updating personal information and account preferences. |
| **Booking Flow** (`booking.html`) | Ticket purchase interface. | Stepper (Tickets -> Coupon), order summary. | Selecting ticket quantities and applying discounts. |
| **Add Attendees** (`add-attendees.html`) | Multi-ticket identities. | Attendee input forms (Name/Phone), booking summary. | Entering name/phone for each person in the order. |
| **Payment** (`payment.html`) | Finalizing multi-attendee order. | Order breakdown, secure form, payment confirmation. | Securely processing total payment for multiple attendees. |
| **Success** (`success.html`) | Transaction confirmation. | Animated checkmark, elegant order summary, thermal printing option. | Finalizing booking and providing confirmation IDs. |
